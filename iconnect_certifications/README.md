# i Connect Consultants - Global Certifications Website

## Run locally
Open `index.html` directly in your browser or use VS Code Live Server.

## Deploy on GitHub Pages
1. Upload all files and the `assets` folder to your repository root.
2. Go to GitHub repository Settings → Pages.
3. Select branch `main` and root folder.
4. Save and wait for the live URL.

## Customization
- Update phone, email, WhatsApp message or form links in `index.html`.
- Certification list can be edited in `script.js`.
- Styling is in `styles.css`.
